# PetFinance

Aplicativo de finanças pessoais para celular com um pet virtual que reage aos seus gastos e orçamentos.

## Como abrir

Sirva esta pasta com um servidor HTTP estático. Com Python 3 instalado, execute `python -m http.server 8000` na pasta do projeto e acesse <http://localhost:8000>.

Na primeira visita, informe seu nome, sua renda média mensal e escolha um pet. O app salva o perfil e os lançamentos no armazenamento local do navegador. O modo de exemplo usa dados fictícios.
